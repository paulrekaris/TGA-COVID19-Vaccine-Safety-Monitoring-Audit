# FOI Systematic Search and Review (2020–2025)

[![OSINT Foundation](https://img.shields.io/badge/OSINT-Foundation%20Standards-1A7A4A?labelColor=000000&style=flat-square)](https://www.osintfoundation.com/osint/Standards.asp)

## Overview

Following completion of the primary audit, a systematic review of TGA's complete FOI disclosure log was conducted using Open Source Intelligence (OSINT) methodology to verify completeness of the audit evidence base and identify any potentially relevant Plan implementation documents.

## Search Methodology

**Date**: 10 January 2026, 9:08–13:41 AEDT (4.5 hours)

**Approach**: OSINT systematic collection and verification

**Scope**: Complete TGA FOI disclosure log (July 2020–December 2025)

### Search Process

**Primary Source:**  
https://www.tga.gov.au/about-us/freedom-information-foi/foi-disclosure-log

**Search Tools:**
- Browser-based keyword search (Ctrl+F) across HTML disclosure log
- Quarterly PDF extracts where HTML log incomplete
- Cross-referencing against existing repository documents

**Search Terms Applied:**
- "COVID vaccine safety"
- "pharmacovigilance"
- "AEFI COVID"
- "VSIG COVID"
- "Safety Monitoring Plan"
- "enhanced monitoring"
- Advanced search: site:tga.gov.au filetype:pdf

**Quality Control Measures:**
- All matches cross-referenced against existing repository
- Promising candidates examined in full text
- Date ranges verified against log timestamps
- Independent verification of findings completeness

**Search Parameters:**
- **Timeframe**: July 2020–December 2025
- **Document type**: Section 11C public releases only
- **Exclusions**: Business exemptions excluded from review
- **Deep-dive verification**: Three promising candidates reviewed in detail (FOI 25-0220, 2389-01, 3727-04)

**OSINT Principles Applied:**
- Systematic source review (complete disclosure log)
- Keyword-based identification (targeted search terms)
- Deep-dive verification (detailed examination of candidates)
- Cross-reference validation (comparison with existing repository evidence)

### Limitations

- Reliant on TGA's accurate and complete disclosure log maintenance
- Search limited to publicly released FOI documents (s.11C releases only)
- Keyword-based approach may miss documents using alternative terminology
- No access to refused or partially released FOI documents

## Detailed Candidate Assessment

### FOI 25-0220
**Description**: ACV meeting minutes on COVID-19 AEFI reporting rates (September 2025)

**Content**: Discussion focused on raw AEFI reporting rate data without Plan implementation framework references.

**Assessment**: Raw data focus, no Plan/VSIG references. Excluded from audit scope.

### FOI 2389-01
**Description**: Pfizer COVID-19 vaccine evaluation and AESI lists (January 2021)

**Content**: Pre-approval delegate overview for Comirnaty provisional registration. Predates the February 2021 Safety Monitoring Plan. Contains efficacy/safety evaluation and ACV advisory questions but no Safety Plan or monitoring framework references.

**Assessment**: Predates audit scope (January 2021; Plan published February 2021). Excluded from audit scope.

### FOI 3727-04
**Description**: Pharmacovigilance investigations – fatal AEFI case documentation (2023)

**Content**: Two-page documentation of single fatal AEFI case (19-year-old female, cardiac arrest, "unlikely causality" coded as "possibly linked"). Individual case review without VSIG procedures, Plan framework references, or process documentation.

**Assessment**: Single case review without systematic process documentation. Excluded from audit scope.

## Analysis

### Document Characteristics

All three candidates yielded zero Plan implementation evidence. Documents contained:
- Raw AEFI reporting rate discussions (FOI 25-0220)
- Pre-approval evaluations predating the Plan (FOI 2389-01)
- Individual case reviews without systematic process documentation (FOI 3727-04)

The remaining 22 FOIs demonstrate consistent patterns: raw AEFI data, case reviews, and technical assessments—without:
- Safety Plan framework references
- VSIG integration protocols
- Plan-level governance documentation
- Evidence of systematic tracking against Plan objectives

### Implications

This systematic review reinforces the audit finding that documentation gaps are comprehensive across the entire FOI corpus, not selective. The absence of Plan framework references is consistent across all 500+ reviewed FOI releases.

## Scope Exclusions

Documents were excluded where they:
- Predated the Plan's publication (February 2021)
- Addressed specific safety signals rather than monitoring processes
- Contained raw AEFI data without Plan framework integration
- Focused on pre-market evaluation rather than post-market surveillance
- Lacked references to Plan strategies, VSIG procedures, or enhanced monitoring governance

All 22 additional FOIs beyond FOI 4029 and FOI 5082 fall outside audit scope—they do not contain evidence regarding implementation of the Plan's 17 strategies as distinct, documentable processes.

### Important Distinction: Pharmacovigilance Plan v Safety Monitoring Plan 

FOI log references to "COVID Vaccine Pharmacovigilance Plan" refer to the national policy umbrella (Cabinet/DoH).[^1]  

**Audit scope**: TGA's **COVID-19 Vaccine Safety Monitoring Plan (February 2021)**—operational implementation framework (17 strategies/20 outputs).[^2]

[^1]: FOI 4029-01 (national pharmacovigilance framework context)  
[^2]: https://www.tga.gov.au/sites/default/files/covid-19-vaccine-safety-monitoring-plan.pdf

## Implications for Audit Evidence Base

### Complete Evidence Collection
Systematic review of 500+ FOI releases (2020–2025) confirms FOI 4029 suite and FOI 5082 represent the complete available evidence of Plan implementation in the public FOI corpus.

### Repository Coverage Validation
The audit repository contains all identified Plan implementation evidence from the complete FOI disclosure log—comprehensive coverage achieved.

### Findings Confirmation
Complete absence of Plan framework references across the entire FOI corpus confirms the audit finding: enhanced monitoring framework implementation cannot be verified through documentary evidence. The documentation gap is comprehensive and systemic, not selective.

### Evidence Base Completeness
No additional FOI documents were identified that would alter implementation status ratings for the 20 Plan outputs assessed in the audit.

## Conclusion

**Evidence collection complete**: OSINT systematic review of 500+ FOI releases confirms FOI 4029 suite and FOI 5082 represent all available Plan implementation evidence in the public FOI corpus.

**Repository coverage validated**: Core documents (FOI 4029 suite, FOI 5082) capture all available Plan implementation evidence from the complete FOI disclosure log.

**Documentation gap confirmed**: Absence of Plan framework references, VSIG integration protocols, and systematic tracking documentation across the entire FOI corpus validates audit findings based on complete available evidence.

**Methodological transparency**: Systematic OSINT search approach enables independent replication and verification of evidence base completeness.

**Recommendation**: No additions to audit evidence base required.
