## Overview

After completing the main audit, I conducted a systematic review of TGA's complete FOI disclosure log employing Open Source Intelligence (OSINT) methodology to verify I hadn't missed any relevant Plan implementation documents.

**Methodology**: OSINT systematic collection and verification

**Scope**: Complete TGA FOI disclosure log (July 2020–Dec 2025). Reviewed HTML log and quarterly PDF extracts manually using keyword search.

## Candidates Reviewed

### FOI 25-0220
**Description**: ACV meeting minutes on COVID-19 AEFI reporting rates (September 2025)

**Finding**: Discussion focused on raw AEFI reporting rate data. No Plan implementation framework references.

**Assessment**: Raw data focus, no Plan/VSIG references. Not relevant.

### FOI 2389-01
**Description**: Pfizer COVID-19 vaccine evaluation and AESI lists (January 2021)

**Finding**: Pre-approval delegate overview for Comirnaty provisional registration. Predates the February 2021 Safety Monitoring Plan. Contains efficacy/safety evaluation and ACV advisory questions but no Safety Plan or monitoring framework references.

**Assessment**: Predates audit scope (January 2021; Plan published February 2021). Not relevant.

### FOI 3727-04
**Description**: Pharmacovigilance investigations – fatal AEFI case documentation (2023)

**Finding**: Two-page note documenting single fatal AEFI case (19-year-old female, cardiac arrest, "unlikely causality" coded as "possibly linked"). Individual case review with no VSIG procedures, Plan framework references, or process documentation.

**Assessment**: Single case review, no VSIG/Plan connection. Not relevant.

## What This Shows

All three candidates yielded zero Plan implementation evidence. They contain:
- Raw AEFI reporting rate discussions (25-0220)
- Pre-approval evaluations predating the Plan (2389-01)
- Individual case reviews without systematic processes (3727-04)

The remaining 22 FOIs follow the same pattern: raw AEFI data, case reviews, and technical assessments—but no:
- Safety Plan framework references
- VSIG integration protocols
- Plan-level governance documentation
- Evidence of systematic tracking against Plan objectives

This reinforces the audit finding that documentation gaps are comprehensive across the entire FOI corpus, not selective.

## Scope Exclusions

Documents were excluded where they:
- Predated the Plan's publication (February 2021)
- Addressed specific safety signals rather than monitoring processes
- Contained raw AEFI data without Plan framework integration
- Focused on pre-market evaluation rather than post-market surveillance
- Lacked references to Plan strategies, VSIG procedures, or enhanced monitoring governance

All 22 additional FOIs beyond FOI 4029 and FOI 5082 fall outside audit scope—they don't contain evidence about whether the Plan's 17 strategies were implemented as distinct, documentable processes.

### Important Distinction: Pharmacovigilance Plan v Safety Monitoring Plan 
FOI log references "COVID Vaccine Pharmacovigilance Plan" = national policy umbrella (Cabinet/DoH).[^1]  
**Audit scope**: TGA's **COVID-19 Vaccine Safety Monitoring Plan (Feb 2021)**—operational implementation (17 strategies/20 outputs).[^2]

[^1]: FOI 4029-01 (national PV framework context)
